Blueprint: uniform bound g(u) ≤ 1/18 on (-∞, 0]

Settings
--------
Let X ~ N(0,1). For u ∈ ℝ, write 𝔼[·] for expectation with respect to X.


Definitions (matching main.tex)
-------------------------------
1) Standard normal quantities:
   - φ(u) := (1/√(2π)) exp(-u^2/2)
   - Φ(u) := ∫_{-∞}^u φ(s) ds
   - Φ̄(u) := 1 - Φ(u) = ∫_u^∞ φ(s) ds

2) Inverse Mills ratio:
   - E(u) := φ(u) / Φ̄(u).

3) Auxiliary functions:
   - d(u) := E(u) - u.
   - g(u) := E(u)^2 ( 3E(u)^2 - 4uE(u) + u^2 - 2 ).


Statement
---------
Lemma (main.tex Lemma “g-uniform-negative”):
  For all u ≤ 0, one has
    g(u) ≤ 1/18.


Dependencies / facts used
-------------------------
A) Smoothness and basic bounds for E:
   - Φ̄(u) > 0 for all u, hence E is smooth on ℝ.
   - For u ≤ 0, Φ̄(u) ≥ 1/2, so E(u) = φ(u)/Φ̄(u) ≤ 2φ(u).
   - Therefore E(u) → 0 as u → -∞.

B) Derivative identity:
   - E'(u) = E(u)^2 - uE(u).
   - (From the previous section) g'(u) can be written as
       g'(u) = 2 E(u)^2 H(u),
     where, with d(u)=E(u)-u,
       H(u) := u^2 d(u) + 6u d(u)^2 + 6 d(u)^3 - u - 4 d(u).
     Since E(u) > 0, the critical points of g are exactly the solutions of
       H(u)=0.

C) Sign at 0 (from Lemma “g-decreasing-positive”):
   - g(0) = 12/π^2 - 4/π = -4(π-3)/π^2 < 0.

D) Rational function bound (from rational_function_bound):
   For all r ∈ (0,1),
     r(4-r)(1-r)^2 / (r^2 - 6r + 6)^2 ≤ 1/18.


Goal
----
Show that sup_{u≤0} g(u) ≤ 1/18.


Proof steps (outline)
---------------------
Step 1: Continuity and limit at -∞.
  Since E is smooth, g is continuous on ℝ.
  For u ≤ 0, Φ̄(u) ≥ 1/2 implies E(u) ≤ 2φ(u). Hence E(u) → 0 and
  |u|E(u) ≤ 2|u|φ(u) → 0 as u → -∞. In particular u^2 E(u)^2 → 0 as u → -∞.
  Using g(u)=E(u)^2(3E(u)^2-4uE(u)+u^2-2), it follows that g(u) → 0 as u → -∞.

Step 2: Reduce to the case when the supremum is positive.
  Let S := sup_{u≤0} g(u).
  If S = 0, then g(u) ≤ 0 ≤ 1/18 for all u ≤ 0 and we are done.
  Otherwise S > 0.

Step 3: Show S is attained at an interior maximizer u* < 0.
  We have g(0) < 0 (Fact C), so the maximizer cannot be u=0.
  Also g(u) → 0 as u → -∞, so for S > 0 we can choose M large with
    sup_{u≤-M} g(u) < S/2.
  Then S = max_{u∈[-M,0]} g(u), and continuity gives existence of a maximizer
  u* ∈ [-M,0]. Since g(0) < 0, this maximizer satisfies u* < 0, hence u* is an
  interior maximizer for the half-line (-∞,0].

Step 4: Critical point condition.
  At an interior maximizer u* < 0 we have g'(u*) = 0. By Fact B, E(u*) > 0 and
  thus g'(u*) = 0 is equivalent to
    H(u*) = 0,
  where H(u) = u^2 d + 6u d^2 + 6 d^3 - u - 4d and d=d(u)=E(u)-u.

Step 5: Introduce the parameter r := -u*/d(u*) ∈ (0,1).
  Let d* := d(u*) and define
    r := -u*/d*.
  Since u* < 0 and d* > 0, we have r > 0.
  Also E(u*) = u* + d* = d*(1 - r) > 0, hence 1 - r > 0 and r < 1.
  Therefore r ∈ (0,1).

Step 6: Solve H(u*)=0 for d*^2 in terms of r.
  Substitute u* = -r d* into H(u*)=0:
    0 = u*^2 d* + 6u* d*^2 + 6 d*^3 - u* - 4d*
      = (r^2 - 6r + 6) d*^3 + (r - 4) d*.
  Divide by d* > 0:
    (r^2 - 6r + 6) d*^2 + (r - 4) = 0,
  so
    d*^2 = (4 - r) / (r^2 - 6r + 6).

Step 7: Evaluate g at the critical point u* and simplify.
  Use the definition
    g(u) = E(u)^2 ( 3E(u)^2 - 4uE(u) + u^2 - 2 ).
  At u*, we have E(u*) = u* + d* = d*(1 - r) and u* = -r d*.
  A direct substitution gives
    g(u*) = d*^2 (1 - r)^2 ( (3 - 2r) d*^2 - 2 ).

  Substitute the expression for d*^2 from Step 6; the numerator simplifies to
    (3 - 2r)(4 - r) - 2(r^2 - 6r + 6) = r,
  hence
    g(u*) = r(4-r)(1-r)^2 / (r^2 - 6r + 6)^2,
    with r ∈ (0,1).

Step 8: Apply the rational function bound and conclude.
  By Fact D, g(u*) ≤ 1/18.
  Since u* attains the maximum S on (-∞,0], we have for all u ≤ 0:
    g(u) ≤ g(u*) = S ≤ 1/18.


End of blueprint.
