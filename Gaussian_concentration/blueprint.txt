
Goal:
Formalize Gaussian concentration for an L-Lipschitz function
f : (Fin n -> ℝ) -> ℝ
under the standard product Gaussian measure γ_n.

Target theorem shape:
```
theorem gaussian_concentration_one_sided
    {n : ℕ} {f : (Fin n -> ℝ) -> ℝ} {L t : ℝ}
    (hL : LipschitzWith (ENNReal.ofReal L) f)
    (hLpos : 0 < L)
    (ht : 0 ≤ t) :
    γ n {x | f x - ∫ y, f y ∂(γ n) ≥ t}
      ≤ ENNReal.ofReal (Real.exp (-(t^2) / (2 * L^2)))
```

Mathlib has Gaussian material for real Gaussian measures and abstract Gaussian facts, so I would base the file on `Mathlib.Probability.Distributions.Gaussian.Real` and maybe `Gaussian.Fernique` if you want integrability support. ([leanprover-community.github.io](https://leanprover-community.github.io/mathlib4_docs/Mathlib/Probability/Distributions/Gaussian/Basic.html?utm_source=openai))

Core definitions:
```
abbrev E (n : ℕ) := Fin n -> ℝ

def γ1 : Measure ℝ :=
  ProbabilityTheory.gaussianReal 0 1

def γ (n : ℕ) : Measure (E n) :=
  Measure.pi fun _ : Fin n => γ1
```

Chernoff bound:

```
theorem chernoff_from_mgf

    {X : Ω -> ℝ} {σ t : ℝ}
    (ht : 0 ≤ t)
    (hmgf : ∀ λ ≥ 0,
      ∫ ω, Real.exp (λ * X ω) ∂μ ≤ Real.exp (λ^2 * σ^2 / 2)) :
    μ {ω | X ω ≥ t}
      ≤ ENNReal.ofReal (Real.exp (-(t^2) / (2 * σ^2))) := by
  -- Markov inequality on exp (λX)
  -- optimize λ = t / σ^2
```

Final theorem:
```
theorem gaussian_concentration_one_sided
    {n : ℕ} {f : E n -> ℝ} {L t : ℝ}
    (hL : LipschitzWith (ENNReal.ofReal L) f)
    (hLpos : 0 < L)
    (ht : 0 ≤ t) :
    γ n {x | f x - ∫ y, f y ∂(γ n) ≥ t}
      ≤ ENNReal.ofReal (Real.exp (-(t^2) / (2 * L^2))) := by
  apply chernoff_from_mgf ht
  intro λ hλ
  exact herbst_mgf_bound hL (le_of_lt hLpos) hλ
```

Practical advice:
Start by proving everything after `herbst_mgf_bound`. Then keep `herbst_mgf_bound` as an axiom or theorem placeholder. The real formalization bottleneck is Gaussian log-Sobolev plus the differentiability or approximation theory for Lipschitz functions.
